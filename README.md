### ⚡ About Me

- 🔭 **Current Focus:** Engineering decoupled distributed services with **Apache Kafka** event buses, **BullMQ** job workers, and **Redis** distributed locks.
- ⚡ **Performance Optimization:** Tuning **PostgreSQL** query execution plans with composite B-Tree indexes across millions of transactional records (cutting latency from 991ms to 180ms).
- 🧠 **AI & RAG Systems:** Building contextual document retrieval pipelines using **LangChain**, **PgVector**, and local **Ollama (Llama 3)** models.
- 🌐 **Live Portfolio:** Explore interactive architecture case studies at [kenilpatel.dev](https://kenilpatel.dev).
- 💬 **Ask me about:** Node.js, Express, TypeScript, Kafka message queues, Redis locking patterns, and PostgreSQL optimization.
